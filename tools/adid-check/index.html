ADID 중복 검사

여러 엑셀(.xlsx) 파일의 ADID를 모아 중복을 찾습니다. 파일은 이 브라우저 안에서만 분석되며 외부로 전송되지 않습니다.

1파일 올리기

.xlsx 파일을 여기에 끌어 놓거나 클릭해서 선택
여러 파일을 한 번에 선택할 수 있습니다
올린 파일 없음
#파일명크기상태

2검사

기본값은 대소문자를 구분하지 않고(abc = ABC), 앞뒤 공백을 지운 뒤 비교합니다.
찾는 열 제목: ADID (구글 광고 ID / 기기식별값), date (열 위치·제목 행 위치는 상관없음)
